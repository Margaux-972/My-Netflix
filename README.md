# 🎬 Netflix Frontend Clone (Static View)

A simplified frontend clone of Netflix displaying categories of movies and TV shows as visual rows, without interaction or detailed views.

## ✨ Overview

This project replicates the visual layout of Netflix with multiple categories of content. It focuses purely on the UI display of movie and series posters, without clickable interactions or additional details.

## 🚀 Key Features

### 🎥 Home Page Layout

- Netflix-style interface
- Multiple content categories

### 📺 Categories / Rows

- Movies and series grouped by categories (e.g., trending, popular, etc.)
- Horizontal rows of poster images

### 🖼️ Poster Display

- Each item is represented by its poster image
- Clean and grid-like visual organization

### ⚡ Static UI

- No clickable elements
- No navigation to details pages
- No pop-ups or modals

## 🛠️ Tech Stack

### Frontend

- React
- CSS / Styled Components

### Data

- static JSON

## 🧩 How It Works

The app fetches or loads a list of movies and series
Content is displayed in horizontal rows
Each row represents a category
Only poster images are displayed
No interaction is available on the posters

## 📸 Features Details

### 📺 Categories

- Multiple sections (e.g., Trending, Popular, Top Rated)
- Each section displays a row of posters

### 🖼️ Posters

- Static images of movies and series
- No hover interaction
- No click actions
